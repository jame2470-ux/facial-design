## วิธีอัปโหลด

อัปโหลดไฟล์ `index.html`, `style.css`, `script.js` และ `README.md` เข้า repository `facial-design` จากนั้นเปิด GitHub Pages ที่ Settings → Pages → Source: Deploy from a branch → Branch: main / root
